# HICAM Browser & Web Automation

Gives Hermes the ability to fetch web pages and do basic browser automation as
part of its reasoning — useful for research, checking sources, or pulling live
information into a conversation.

## What this includes
- **Web fetch** — Hermes can retrieve and read the content of a URL you give it.
- **Browser tool** — for pages that need JavaScript execution or interaction
  (already part of the core Hermes toolset; this skill just documents usage
  patterns relevant to HICAM's research workflows).

No additional credentials are required. This skill is enabled by default in the
core Hermes toolset; this folder exists to flag it as one of the categories you
selected during setup.
